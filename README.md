# Law-wright.github.io

Personal cybersecurity portfolio. The site is `index.html`. The resume link points at `resume.pdf`. There is no install or build step.

## Run locally

From this directory:

```bash
python3 -m http.server 8765
```

Open http://127.0.0.1:8765/

Stop the server with Ctrl+C.

Opening `index.html` directly in a browser also works. The local server is the closer check, because the resume link and page paths behave the way they will on GitHub Pages.
