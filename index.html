Secure Employee Management System

This system is built so the threat model stays in charge of the controls. Thirteen STRIDE threats map to NIST SP 800-53, and the write-up keeps the residual gaps visible. Least privilege for three roles, a leave workflow that blocks self-approval, account lockout, and an audit log that excludes secrets are what that model required. Those same paths were then checked for SQL injection and stored XSS, on login, leave requests, and the audit log. 44 JUnit 5 tests pass; Claude and Cursor helped draft them, and each was reviewed against the model. Scanning removed a high-severity regex denial-of-service bug and cut dependency CVEs from 61 to 34.

NetWatch

NetWatch answers a detection question a capture file cannot: which Windows event belongs with this traffic. It correlates up to 100,000 packets with Security, System, Application, and Sysmon, and each alert stays linked to the rows behind it. Three rules, mapped to MITRE ATT&CK T1110.001 and T1046, flag failed logons, SYN port sweeps, and volume spikes. Fifty-eight pytest tests check those rules on seeded data, and a STRIDE model records the detection gaps.

Software Supply Chain Security Research

Faculty-supervised research on a supply-chain failure: the packages you installed are not always the code that runs. Four briefs cover open-source attacks (Log4Shell, event-stream, and xz), runtime software bills of materials, malicious AI models, and expert risk ranking with DEMATEL. MEM-SBOM, published in Computers & Security, is the evidence: 10 loaded-versus-installed mismatches across 51 Python applications, and 83.3% fewer false-positive vulnerability reports in one runtime-SBOM case.
